Q: How do I upload this theme?
A: ZIP the files and upload to Shopify Admin → Themes → Add Theme

Q: Can I customize colors?
A: Yes! Shopify Admin → Themes → Customize → Theme Settings → Colors

Q: Where do I change the store name?
A: Shopify Admin → Settings → Store Details

Q: How do I add products?
A: Convert sample-products.json to CSV, then Products → Import

Q: How long until I can launch?
A: 3-6 hours (upload 10min, configure 2-4h, test 1-2h)

Q: Can I modify the design?
A: Yes! Edit Liquid templates & CSS files directly

Q: What if I break something?
A: Shopify keeps version history - you can revert

Q: Can I add more products?
